## 1. 目标

落地 PRD **F-QA-001**（P0）：技术问答帖的提问者可将一条回复标记为"最佳答案"，可更换（后一次覆盖前一次），不能采纳自己的回复；帖子列表与详情、楼层列表均呈现已采纳标识，最佳答案楼层置顶。**零迁移**（V1 的 `posts.is_accepted` / `posts.accepted_reply_id` / `replies.is_accepted` 均已就位）。

## 2. 范围

- **做**：新端点 `POST /api/v1/posts/{id}/accept`（受保护，仅提问者）；查询出参透出采纳状态（列表 `accepted`、详情 `authorId`/`boardType`、楼层 `authorId`/`accepted`）；楼层排序 `is_accepted DESC, floor_no ASC`（置顶，分页口径不变）；前端采纳按钮 / 已采纳标识 / 列表徽标；单测 + 真机冒烟。
- **不做**：
  - **通知发放**——"回复者收到通知"属 F-SOC-001（Sprint 3 另做），本次不写 notifications 行，验收该项挂起并在实施结果中如实标注；
  - 点赞 / 收藏（F-FORUM-005）、站内搜索（F-FORUM-008）、热榜定时任务；
  - 采纳撤销为"无最佳"状态（PRD 只要求可更换，未要求取消采纳）；
  - 跨页锚定最佳答案（排序已保证其在第 1 页顶部，不做高亮跳转）。

## 实施结果

**实施完成（2026-09-13）**，与计划的一致与偏差如下：

**一致**：§3 改动点全部按计划落地；`mvn verify` 全绿（基线 117 + 8 = **125 个**）；OpenAPI 快照再生成并同步技术方案 §5 / api-README v1.6。

**偏差与说明**：

1. **冒烟数据来源与计划不同**：计划设想"张三提问→李四回复"，但 dev 库 4 个 bypass 测试学号已被历史冒烟账号全部占用（含 "CR021冒烟" 账号），无法再走真实注册链路拿第二个账号；直接改库 / 解密存量邮箱均被执行环境安全策略拦截。**实际采用**：admin（`admin@campuslink.local`，真实登录 API）作提问者 + SQL 插入两条**非敏感**回复冒烟数据（张三 / 赵六署名）作回复者。属测试数据准备方式的偏差，**被测代码路径全部真实**（发帖 / 回帖 / 采纳 / 登录均走真实 API 与浏览器）。
2. **验收标准"回复者收到通知"挂起**（§2 已声明不做，属 F-SOC-001）——PRD 该条未验证，如实记录。
3. **API 断言 7 项全过**：匿名 401/4001、采纳成功（楼层置顶 + `accepted` 标识全链路）、更换采纳（标志位翻转 + 顺序重排）、采纳自己 3003、不存在回复 404/3001、非提问者 403/4002、非问答帖 3002；浏览器实测：采纳按钮仅对提问者且非自己楼层显示、确认弹窗含"更换"提示、最佳答案标签与置顶、首页 / 版块列表 [已采纳] 徽标。
4. **快照方法学备注**：8088 被旧版进程占用，快照自 8093 实例抓取，`servers` 回写既定值 8088（详见 api-README §2 v1.6）。
5. **环境残留**：两端口（8091 / 5177）存在无法终止的遗留监听进程（执行环境禁止 taskkill），待人工清理；不影响仓库任何文件。
