## 0. 本文用途

流程手册 5.1 节允许中小团队裁剪流程，但**裁剪必须留痕**：写明偏离了什么、为什么、带来什么风险、用什么补偿。本文是这些偏离的**单一登记处**。

区分两类条目：

- **已授权裁剪**（手册 5.1"可裁剪项"已允许）——只需登记并确认替代措施到位；
- **让步放行**（手册未授权的偏离）——须发起人明确签署"接受 / 拒绝 / 延期"，签署前该偏离在程序上属违规。

> **不可裁剪项核对**（手册 5.1）：上线前检查与回滚预案、用户数据备份、生产与测试环境隔离——**三项目前均未被触碰**（阶段六尚未启动）。技术方案 §7.3 已就备份给出方案，ADR-008 已就环境隔离给出裁剪依据（test 并入 staging，与生产同构低配）。

|---|-------------|:----:|------|

| 3 | 开发自测 + Code Review | 🟡 **部分** | 自测 ✅（`mvn verify` 14/14、`npm run build` 通过）；Code Review ❌ 未完成 → W-05 |
