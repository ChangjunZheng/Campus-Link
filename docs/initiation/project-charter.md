## 1. 项目概述

Campus-Link 是面向**重庆工程学院计算机专业学生**的垂直交流论坛（核心方向：固定版块体系、Markdown 帖子与代码高亮、问答最佳答案采纳、站内通知与搜索、学籍核验注册），基于"**问有所答、学有同伴、求职有路**"的定位，解决计算机专业学生交流分散、经验信息不可沉淀的问题。本期服务范围**仅限本校**，不外扩。

本章程正式授权 Campus-Link 项目启动，授权项目经理在立项评审通过后组织团队开展需求阶段工作。项目全流程遵循[研发流程手册](../process-handbook.md)。

## 2. 项目目标（SMART，草案）

| # | 目标 | 度量方式 | 时限 |
|---|------|---------|------|
| G1 | 完成 MVP（Web 论坛核心：版块、发帖回复、采纳、通知、搜索、审核、后台、**学籍核验注册**）并在重庆工程学院计算机专业学生社群灰度上线 | 上线且 P0 缺陷清零 | 立项评审通过后约 13 周（见第 4 节） |
| G2 | 验证核心留存与社区健康假设 | 本校 7 日留存 ≥ 20% **且**技术问答 48h 回复率 ≥ 70%（假设值，分母为单校计算机专业学生基数，见 [BRD](brd.md) 第 7 节） | 上线后 30 天 |
| G3 | 建立合规与运营基线 | 隐私政策上线、内容审核机制运行、**学籍名册导入完成**；ICP 备案视部署形态而定（见 R2） | MVP 上线前 |

## 3. 范围边界

**In Scope（本期做）**

- 固定版块体系（技术问答 / 学习资源 / 面经求职 / 竞赛交流 / 课程交流 / 闲聊灌水）；
- **学籍核验注册（学号 + 姓名比对，限重庆工程学院学生）**；
- 发帖与楼层式回复（Markdown 正文 + 代码块语法高亮 + 标签）；
- 技术问答帖采纳最佳答案；
- 点赞、收藏、站内通知；
- 站内搜索（标题 + 标签）；
- 内容安全：机审 + 举报 + 处置；
- 运营管理后台：登录权限、内容处置台、举报工单；
- 账号体系：注册登录、个人主页、账号注销。

**Out of Scope（本期不做）**

- 私信与 IM；
- 组队广场（课程 / 竞赛 / 开源组队）；
- 等级声望体系；
- 学籍名册的自动化同步（本期为人工导入，增量更新机制列 P1）；
- 匿名发帖（P2）；
- 微信小程序 / 原生 App（P2 评估，首发为 Web）；
- 个性化推荐算法（MVP 用时间序 + 简单热门排序）；
- 盈利相关功能（招聘合作 / 会员等）。
