## 3. Sprint 拆解建议（2 周 / Sprint）

> 章程原估开发 6 周（3 个 Sprint）。按 P0 从 18 条增至 19 条（新增学籍核验），建议调整为 **8 周 / 4 个 Sprint**，更贴近单人开发节奏。
>
> 本节为**建议稿**。若 `docs/development/sprint-1.md` 已产出，以该文件为执行依据，本节仅作整体节奏参考。

### Sprint 1 · 地基与账号链路（阻塞项清零后启动）

| 任务 | 产出 |
|------|------|
| 仓库脚手架 | Spring Boot 3 + Maven 工程；Vue 3 + Vite 工程；Docker Compose（MySQL 8 + Redis 7） |
| 数据库 | `sql/schema.sql` 全表 DDL + 6 版块种子数据（按技术方案 4.1 / 4.2） |
| 公共层 | 统一响应 `R`、错误码枚举、全局异常处理、参数校验、审计切面 |
| **安全地基** | **Markdown 渲染服务（flexmark + jsoup 白名单）+ XSS 用例回归**——这是论坛安全生命线，务必第一个 Sprint 就做掉 |
| 鉴权骨架 | Spring Security + JWT、角色校验、未登录只读 |
| **学籍核验 + 注册登录** | F-ACC-004（名册导入 + 核验 + 限流）、F-ACC-001（验证码注册登录） |

**Sprint 1 出口**：能用学号 + 姓名 + 邮箱验证码注册成功，能登录，能看到个人主页；发一段含 `<script>` 的 Markdown 不产生 XSS。

> **上表为 2026-08-30 的建议稿，实际交付有 4 处不同**（以 [Sprint 1 计划](development/sprint-1.md) 与代码为准）：① 技术栈为 **Spring Boot 4.1 + JDK 21**，非表中的 Spring Boot 3（[CR-007](change-log.md)）；② 开发期依赖栈用**本机原生 MySQL / Redis，不用 Docker**，`docker-compose.dev.yml` 保留至发布阶段（[CR-011](change-log.md)）；③ 表结构由 **Flyway 迁移** `backend/src/main/resources/db/migration/` 承担，`sql/schema.sql` 已随 `backend/sql/` 目录删除（[CR-014](change-log.md)）；④ 账号上下文按 **ADR-012 四层结构**（domain / application / infrastructure / web）落地，非表中的传统三层（[CR-008](change-log.md)）。
