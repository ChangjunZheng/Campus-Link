## 4. 数据模型

- ER 图（占位）；
- 核心表结构：表名、关键字段、索引设计、数据量级预估与分表策略（如有）；
- 数据保留与删除策略（合规相关，如账号注销的数据处理）。

## 5. 接口契约

- 接口风格与规范：REST（OpenAPI 3.x）/ GraphQL，文档存放位置；
- 统一约定：鉴权方式、错误码结构、分页约定、时间格式（UTC/时区）；
- 核心接口示例（写 2~3 个主链路接口的请求 / 响应结构即可）。

## 7. 非功能设计

- 性能：热点数据缓存策略、慢查询预防；
- 安全：认证授权方案、敏感数据存储（加密/脱敏）、UGC 内容审核链路；
- 可用性：依赖故障的降级预案、数据备份策略。

## 8. 部署架构

- CI/CD 流水线设计（构建 → 扫描 → 单测 → 部署）；
- 监控与告警接入方案。
